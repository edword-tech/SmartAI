## 🚀 使用流程

### 场景：配置训练加速

1. **访问训练加速页面**
   ```
   左侧菜单 → 算力管理 → 训练加速
   ```

2. **选择任务**
   ```
   在任务列表中找到要优化的任务
   ```

3. **配置优化项**
   ```
   - 切换到"数据加载优化"Tab → 创建配置
   - 切换到"分布式训练"Tab → 创建配置
   - 切换到"检查点配置"Tab → 创建配置
   - 切换到"显存优化"Tab → 创建配置
   ```

4. **应用优化**
   ```
   点击任务行的"优化"按钮，自动应用所有配置
   ```

### 场景：使用算力编排下发任务

1. **访问算力编排页面**
   ```
   左侧菜单 → 算力管理 → 算力编排
   ```

2. **查看调度策略**
   ```
   查看均衡调度、最小碎片调度、弹性调度的配置
   ```

3. **下发任务**
   ```
   点击"下发任务"按钮
   - 填写任务信息
   - 选择调度策略（balanced/min_fragment/elastic）
   - 提交
   ```

4. **优化调度**
   ```
   点击"优化调度"按钮，系统自动优化资源分配
   ```
