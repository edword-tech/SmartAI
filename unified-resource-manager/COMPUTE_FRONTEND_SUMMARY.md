## 🚀 使用流程示例

### 场景 1：监控资源状态

1. **访问算力感知页面**
   ```
   左侧菜单 → 算力感知
   ```

2. **查看资源状态**
   ```
   - 查看统计卡片了解整体情况
   - 查看资源状态表格了解详细信息
   - 资源状态每10秒自动刷新
   ```

3. **绑定资源**
   ```
   - 点击资源行的"绑定"按钮
   - 输入任务ID
   - 确认绑定
   ```

### 场景 2：配置资源切分

1. **访问算力质量页面**
   ```
   左侧菜单 → 算力质量
   ```

2. **切换到切分配置Tab**
   ```
   点击"切分配置"Tab
   ```

3. **创建切分配置**
   ```
   - 点击"创建切分配置"按钮
   - 填写配置信息（名称、资源类型、内存、核心数等）
   - 提交
   ```

### 场景 3：使用算力编排下发任务

1. **访问算力编排页面**
   ```
   左侧菜单 → 算力编排
   ```

2. **查看调度策略**
   ```
   查看均衡调度、最小碎片调度、弹性调度的配置说明
   ```

3. **下发任务**
   ```
   - 点击"下发任务"按钮
   - 填写任务信息
   - 选择调度策略（balanced/min_fragment/elastic）
   - 提交
   ```

4. **优化调度**
   ```
   点击"优化调度"按钮，系统自动优化资源分配
   ```

### 场景 4：配置训练加速

1. **访问训练加速页面**
   ```
   左侧菜单 → 训练加速
   ```

2. **选择任务**
   ```
   在任务列表中找到要优化的任务
   ```

3. **配置优化项**
   ```
   - 切换到"数据加载优化"Tab → 创建配置
   - 切换到"分布式训练"Tab → 创建配置
   - 切换到"检查点配置"Tab → 创建配置
   - 切换到"显存优化"Tab → 创建配置
   ```

4. **应用优化**
   ```
   点击任务行的"优化"按钮，自动应用所有配置
   ```
